# loro-wit

WebAssembly Component Model interface for Loro CRDTs.

This crate provides a [WIT](https://github.com/WebAssembly/component-model/blob/main/design/mvp/WIT.md) (WebAssembly Interface Types) interface for Loro CRDTs, enabling usage from any language that supports the WebAssembly Component Model.

## Building

Requires `cargo-component`:

```bash
cargo install cargo-component
```

Build the component:

```bash
cargo component build --release
```

The resulting WebAssembly component will be at `target/wasm32-wasip1/release/loro_wit.wasm`.

## WIT Interface

The WIT interface is defined in `wit/world.wit` and provides:

### Types (`component:loro-wit/types`)
- `peer-id` - Unique peer identifier
- `op-id` - Operation ID (peer + counter)
- `version-vector` - Version vector for sync
- `frontiers` - Document frontiers
- `loro-error` - Error variant type

### Doc Interface (`component:loro-wit/doc`)

#### LoroDoc Resource
- `constructor()` - Create new document
- `peer-id()` - Get peer ID
- `set-peer-id(u64)` - Set peer ID
- `get-text(name)` - Get text container
- `get-map(name)` - Get map container  
- `get-list(name)` - Get list container
- `commit()` - Commit changes
- `export-snapshot()` - Export as snapshot
- `export-updates()` - Export updates
- `import-bytes(data)` - Import data
- `fork()` - Fork document

#### LoroText Resource
- `insert(pos, text)` - Insert text
- `delete(pos, len)` - Delete text
- `to-string()` - Get content
- `len-unicode()` / `len-utf8()` - Get length

#### LoroMap Resource
- `insert-string/i64/f64/bool/null(key, value)` - Insert value
- `delete(key)` - Delete key
- `get-json(key)` - Get value as JSON
- `keys()` - Get all keys

#### LoroList Resource
- `insert-string/i64/f64/bool/null(pos, value)` - Insert at position
- `push-string/i64(value)` - Append value
- `delete(pos, len)` - Delete items
- `get-json(index)` - Get item as JSON
